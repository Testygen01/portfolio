# Improving Knowledge Base Accessibility Through a Large-Scale Documentation Audit

## Overview

Documentation is only valuable when it is accessible and usable by its intended audience. During my Public Cloud Team rotation, I conducted a large-scale effort to review and improve the accessibility of the team's knowledge base documentation.

The peoject involved auditing approximately 160 technical documents and remediating accessibility issues to improved usability and compliance with accessibility standards.

## Environment

- Knowledge Base Documentation Software
- Technical Writing
- Documentation Governance
- Accessibility Standards Reference

## Problem

Over time, technical documentation had ben created by multiple contributors with varying levels of accessibility awareness.

As a result, documentation quality and accessibility compliance varied across the knowledge base. This created potential barriers for users who relied on assistive technologies.

## Action Taken

I reviewed existing documentation to identify common accessibility issues and areas requiring remediation. The audit focused on document structurem formatting consistency, accessibility compliance, and overall usability.
