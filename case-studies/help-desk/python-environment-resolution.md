# Resolving an Academic Python Environment Configuration Issue

## Overview

A student was unable to complete coursework because the required Python environment would not run successfully on their system.

## Environment

- Python
- Anaconda / Conda
- Mac laptop

## Problem

A student's coursework requirements required a specific Python version and module set that differed from the student's existing environment.

## Actions Taken

- Identified version incompatibilities
- Updated the Conda environment
- Installed the required Python version
- Resolved missing package dependencies using cli work
- Verified successful execution after remediation

## Resolution

The environment was successfully rebuilt and aligned with the student's course requirements. The student was able to continue coursework without escalation to a specialized support team, which would have take much longer.

## Key Takeaways

This issue highlighted the importance of dependency management and environment consistency when supporting academic computing workfflows. And also the importance of rereading original instructions and not blindly trusting a client's perceived problem.
