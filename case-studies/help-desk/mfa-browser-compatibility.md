# Diagnosing a Multi-Factor Authentication Browser Compatibility Issue

## Overview

A user experienced authentication failures when attempting to use a hardware security key and biometric authentication workflow on macOS.

## Environment

- DUO MFA
- FIDO2 Authentication
- Firefox
- macOS

## Problem

The user was unable to complete authentication in Firefox browser despite having valid credentials and hardware-based authentication methods available.

## Actions Take
- Reviewed user's authenticatin workflow
- Identified browser-specific limitations impacting FIDO2 functionality
- Verified the issue was browser-dependent using DUO documentation
- Identified compatibility limitations
- Explained supported authentication methods to client
- Guided the user through alternative secure login options

## Outcome

The user successfully authenticated using an alternative, supported method. 

## Key Takeaways

This experience reinforced the importance of understanding authentication technologies and communicating technical limitations clearly to end users.
