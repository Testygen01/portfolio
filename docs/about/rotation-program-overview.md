# Rotation Program Overview

## Program Structure

The Information Technology Job Rotation Program is a two-year professional development program that provides participants with experience across four different IT organizations.

Each rotation lasts approximately six months and exposes participants to new technologies, operational environments, and busines needs.

The program is designed to develop well-rounded technology professionals by providing experience across multiple disciplines rather than a single specialization.

## My Rotations

### Rotation 1: DoIT General Help Desk

The General Help Desk serves as a primary point of contact for technology support.

This rotation provided experience in:

- Technical troubleshooting
- Customer support
- Identity and Access Management
- Endpoint support
- Incident triage
- Technical communication

### Rotation 2: DoIT Public Cloud Team

The Public Cloud Team supports cloud technologies, governaance, and service enablement across the university.

This rotation provided experience in:

- Amazon Web Services (AWS)
- Cloud governance
- Infrastructure as Code (Terraform)
- Jira automation
- Cloud security
- Technical documentation

### Rotation 3: Center for High Throughput Computing (CHTC)

The CHTC provides computing resources and expertise that enable researchers to perform large-scale scientific computing.

This rotation focuses on:

- Linux systems administration
- HTCondor
- Infrastructure operations
- Research computing
- Data management
- Enterprise systems support
- Configuration management

## Portfolio Organization

The portfolio is organized around case studies drawn from each rotation.

Each case study documents:

- The problem or challenge
- The environment and technologies involved
- Actions taken
- Resolution and outcome
- My takeaway

My objective is not just to show technical accomplishments, but also my problem-solving methodology and professional growth throughout the program.
