# Dell Server Maintenance with Dell iDRAC and RACADM

`Dell iDRAC` `RACADM` `Linux` `Enterprise Hardware`

## Overview

This case covers Dell server maintenance performed through Dell iDRAC, using RACADM from Linux, in an enterprise hardware environment. iDRAC provides out-of-band management of Dell servers, and RACADM is the command-line interface for administering it, including remote operations that do not require operating-system access on the target machine.
