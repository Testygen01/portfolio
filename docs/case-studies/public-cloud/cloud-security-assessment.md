# Enhancing a Cloud Security Assessment Framework
`Risk Management` `Security Frameworks` `Technical Analysis`

## Overview

Cloud projects frequently involve varying levels of security risk depending on their architecture, data handling practices, and access management design. As part of a broader security initiative, I contributed research and assessment development efforts aimed at improving cloud project risk evaluations.

## Environment

- Multi-Cloud 
- CIS Benchmarks
- NIST 800-53
- Cloud Security Alliance Cloud Controls Matrix (CSA CCM)

## Problem

The cloud team sought to strength its ability to evaluate customer cloud environments and identify security risks early in the project lifecycle.

## Actions Taken

I worked closely with the team's cloud security analyst to research industry security frameworks and examine how their controls could be incorporated into cloud assessment activities. 

Some actions I performed:
- Researched CIS Benchmarks
- Evaluated NIST 800-53 controls
- Reviewed CSA Cloud Controls Matrix guidance
- Compared security recommendations across multiple frameworks
- Developed assessment questions focused on:
    - Data storage and protection
    - Identity and access management
    - Resource governance
    - Network access

## Outcome

This security initiative resulted in a draft question framework to strengthen security reviews and support more consistent project assessments. These ten questions provided a foundation for more structured cloud risk evaluations and encouraged earlier security discussions with stakeholders for any cloud-related projects.
